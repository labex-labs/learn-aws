<h1 align="center">AWS を学ぶ</h1>

<p align="center"><strong>実践を中心に段階的に学べる、無料の実用的な学習パスです。</strong></p>

**言語:** [English](README.md) · [简体中文](README_zh.md) · [日本語](README_ja.md) · [Español](README_es.md) · [Français](README_fr.md) · [Deutsch](README_de.md) · [Русский](README_ru.md) · [한국어](README_ko.md) · [Português](README_pt.md)

AWS の基礎、ストレージ、権限から始め、ネットワーク、コンピューティング、データベースを学びます。Web と Serverless のプロジェクトで知識をつなぎ、安全性、監視、メッセージ、ワークフロー、自動デプロイへ進みます。必要に応じて DNS/CDN、コンテナ、共有ストレージ、キャッシュ、分析、AI を探索します。ガイド付きラボから独立課題へ進み、障害診断とクリーンアップを実践します。 選んだ試験のガイドと併用し、AWS 認定試験の準備にも実践を役立てられます。

<td align="center" width="33%"><strong>3. 実践的なプロジェクトを作る</strong><br>ガイド付きの実務に近いシナリオで知識を活用します。</td>
